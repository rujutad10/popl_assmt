Prompt 0: skill file

Write a SKILL.md (YAML header with name and description, then instructions) called scheme-dev for Racket 8.x using #lang racket/base. It must contain: language/version, coding conventions (naming, a one-line declarative comment above each function), how to run and test, a self-review checklist, and known AI failure modes for Scheme. The only allowed built-ins are: define, lambda, let, let*, letrec, named let, if, cond with else, and, or, not, begin, quote, cons, car, cdr, list, c[ad]r compositions up to 4 levels, null?, pair?, eq?, assq, assoc, + - * < > <= >= =, max, display, newline. Forbidden: set!, vectors, hashes, strings, loops, length, append, reverse, map, filter, member, memq, list-ref, list-tail.

Prompt 1: accessors

Using the scheme-dev skill, write three small functions tree-value, tree-left, tree-right for a binary tree that is either () or (value left right). Use only car/cadr/caddr.

Prompt 2: inorder

Using the scheme-dev skill, write one function (inorder t acc) that returns the inorder list of tree t (left, node, right) without append or reverse, using the accumulator to hold the rest of the answer. Add a one-line declarative comment.

Prompt 3: preorder

Same style as inorder: write (preorder t acc) returning node, left, right order, no append/reverse.

Prompt 4: postorder

Same style: write (postorder t acc) returning left, right, node order, no append/reverse.

Prompt 5: height and leaves

Write (height-and-leaves t) that returns (list height leaf-count). Height of () is 0, a single node has height 1, a leaf is a node whose left and right are both (), and the empty tree has 0 leaves. Only whitelisted built-ins.

Prompt 6: printing functions

Write print-inorder, print-all-traversals (inorder, preorder, postorder on three lines) and print-height-and-leaves using the existing helpers. They must use display, and every function must end with a newline. Print nothing at load time.

Prompt 7: tests

Write a Racket test file for S1 covering the examples t1, t2, t3, the empty tree, a single node, and a 10,000-deep chain. It should compare the printed output to expected strings.
