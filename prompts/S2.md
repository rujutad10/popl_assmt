## S2.a — Input and Output

### Prompt 1 — Input Processing

Develop and review the `print-insert-result` function in Racket 8.x. The function must read three inputs (`x`, `lst`, and `n`) from standard input in the specified order, invoke `insert-if-short`, and print the resulting nested list followed by a newline. Ensure that no prompts or additional output are generated.

## S2.b — Helper Functions

### Prompt 2 — List Length Calculation

Implement and verify a custom `my-length` function using recursion or named let. The function should calculate the number of top-level elements in a list and correctly handle empty lists. Do not use the built-in `length` function.

### Prompt 3 — Custom Map Implementation

Implement and review a custom `my-map` function that accepts a function and a list, applies the function to every element, and returns a new list preserving the original order. Handle empty lists correctly without using the built-in `map`.

### Prompt 4 — Conditional List Insertion

Implement and verify `insert-if-short(x, lst, n)`. The function should insert `x` at the beginning of every list whose original length is strictly less than `n`. Ensure that the implementation supports nested lists and empty lists.

## S2.c — Higher-Order Function

### Prompt 5 — make-inserter Implementation

Implement the higher-order function `make-inserter(x, len-ok?)`. It should return a function that recursively processes a nested list and inserts `x` at the beginning of every list satisfying the supplied length predicate. Ensure that the original list length is used when evaluating the condition.

### Prompt 6 — Integration with insert-if-short

Review the integration of `make-inserter` with `insert-if-short`. Verify that `insert-if-short` is implemented using `make-inserter` with the predicate `len < n`. Ensure that the final implementation contains only one definition of `insert-if-short`.
